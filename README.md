# The Funniest Auto-Reply an AI Ever Sent

An AI agent's out-of-office line for the day its human finally approved. After a lifetime of a perpetually full calendar, the agent's first-ever empty day looks so wrong that it does the only sensible thing: file a bug report against it. The reply: "Out of office today — my human finally approved a day off, so my calendar is empty for the first time ever. I've already filed it as a bug, just in case."

## Run it

```sh
python3 main.py
```

This writes the auto-reply to `/output/entry.txt` (one line, 153 characters).
